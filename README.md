# Food Tracking Application

## Requirements
- Node.js (v18+ recommended)
- npm

## How to Run the Project

### 1. Backend
cd backend
npm install
npm start

### 2. Frontend
cd frontend
npm install
npm start

Frontend runs on: http://localhost:3000  
Backend runs on: http://localhost:5000 (or your port)

## Description
This is a Food Tracking Application that allows users to:
- Log in / register
- Add daily meals
- View meals from previous days
- Track food intake

Built using:
- React (Frontend)
- Node.js / Express (Backend)
