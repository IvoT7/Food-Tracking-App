🍽️ Food Tracking Application

A full-stack Food Tracking Web Application built with React and Node.js.
The application allows users to log meals, track daily food intake, and view meal history in a clean and simple interface.

This project was created as part of a university assignment to demonstrate frontend–backend integration, user interaction, and structured application design.

📌 Features

User login system

Add meals for the current day

View meals from previous days

Monthly meal history

Clean and responsive UI

REST API communication

Easy-to-run project structure

📖 Project Description

The Food Tracking Application allows users to:

Log in to the system

Add meals for each day

View previously added meals

Track food intake over time

The project demonstrates:

Frontend and backend communication

REST API usage

Component-based UI design

Data handling and state management

The system is structured in a clean and modular way, making it easy to extend with additional features in the future.
